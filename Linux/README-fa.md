# DrKozol برای لینوکس

این کلاینت با رابط بومی Avalonia ساخته شده و از همان موتور اتصال، اشتراک و مدیریت حجم نسخهٔ ویندوز استفاده می‌کند. فایل این انتشار برای Linux x64 است.

آرشیو را در پوشه‌ای که حساب شما اجازهٔ نوشتن دارد استخراج کنید، سپس اجرا کنید:

```sh
chmod +x DrKozol bin/xray/xray bin/sing_box/sing-box bin/drkozol-awg
./DrKozol
```

در نخستین اجرا لینک اشتراک HTTPS را وارد کنید. پیام پنل، حجم و تاریخ انقضا از اطلاعات همان اشتراک دریافت می‌شوند. سرورها با نام، پرچم و نوع پروتکل کانفیگ نمایش داده می‌شوند. فهرست اشتراک‌ها باز و بسته می‌شود و جست‌وجو و فیلتر پروتکل دارد.

در تنظیمات می‌توانید فارسی یا انگلیسی و تم پیش‌فرض Ocean Dark و پالت‌های رنگی متنوع، OLED، ژاپن و انیمه را با حالت روشن یا تاریک انتخاب کنید. انتخاب شما ذخیره می‌شود. Real Delay و TCP Ping جدا هستند؛ «پینگ اتصال فعلی» هنگام اتصال مسیر فعال را بررسی می‌کند.

حالت System Proxy تنظیم پراکسی GNOME را برای برنامه‌هایی که این تنظیم را رعایت می‌کنند به کار می‌گیرد. برای عبور ترافیک برنامه‌های دیگر، TUN را انتخاب کنید. در تنظیمات، «فعال‌کردن دسترسی TUN» تنها مجوز شبکهٔ موتور تونل را با تأیید سیستم‌عامل فعال می‌کند؛ رابط برنامه با حساب عادی شما اجرا می‌شود. پس از جابه‌جایی موتور یا استخراج مجدد بسته، ممکن است نیاز باشد این مرحله تکرار شود.

اگر محیط لینوکس کتابخانه‌های رابط گرافیکی را ندارد، بسته‌های X11، fontconfig و فونت مناسب فارسی را از مخزن توزیع خود نصب کنید. برای نصب مجوز TUN نیز `pkexec` و `setcap` لازم است. نمونه در Debian/Ubuntu:

```sh
sudo apt install libx11-6 libice6 libsm6 libfontconfig1 libxrandr2 libxi6 libxcursor1 fonts-dejavu-core fonts-noto-core pkexec libcap2-bin
```

بسته شامل Runtime است؛ کتابخانه‌های سیستم‌عامل همچنان لازم هستند. ICU برای پردازش زبان و تاریخ فارسی ضروری است. در Ubuntu، بستهٔ مناسب نسخهٔ سیستم را نصب کنید:

| Ubuntu | کتابخانه‌های ICU و OpenSSL |
| --- | --- |
| 22.04 | `libicu70 libssl3` |
| 24.04 | `libicu74 libssl3t64` |
| 26.04 | `libicu78 libssl3t64` |

مثال Ubuntu 26.04:

```sh
sudo apt install libicu78 libssl3t64 libbrotli1 libgssapi-krb5-2 ca-certificates tzdata zlib1g libstdc++6
```

در توزیع‌های دیگر، بستهٔ ICU و وابستگی‌های Runtime را از مخزن همان توزیع نصب کنید. فهرست نسخه‌ها در [راهنمای رسمی وابستگی‌های .NET در Ubuntu](https://learn.microsoft.com/en-us/dotnet/core/install/linux-ubuntu-install#dependencies) آمده است.
